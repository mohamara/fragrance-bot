# ربات مشاور عطر هوشمند با LangChain و OpenAI

یک ربات تلگرام تخصصی برای مشاوره عطر و اسانس که از LangChain، OpenAI و پایگاه دانش برای ارائه مشاوره‌های حرفه‌ای و شاعرانه در انتخاب و ترکیب عطرها استفاده می‌کند.

## ویژگی‌ها

- 🌹 **مشاور تخصصی عطر**: مشاوره حرفه‌ای با طبع شاعرانه و قدرت کلام بالا
- 🎨 **توصیفات عمیق و شاعرانه**: توصیف حال و هوای عطرها به صورت احساسی و جذاب
- 💫 **ترکیب‌سازی خلاقانه**: آموزش ترکیب عطرها با زمانبندی و نقاط دقیق زدن
- 🎯 **مشاوره شخصی‌سازی شده**: بر اساس شخصیت، سبک زندگی و نیاز هر کاربر
- 📚 **پایگاه دانش عطرها**: استفاده از فایل‌های متنی (.txt) حاوی اطلاعات عطرهای موجود
- 💬 **تاریخچه چت**: ذخیره و استفاده از تاریخچه گفتگو برای مشاوره‌های بهتر
- 👤 **مدیریت کاربران**: شناسایی کاربران و ایجاد پروفایل برای هر کاربر
- 🔍 **جستجوی معنایی**: استفاده از Vector Store برای جستجوی هوشمند در پایگاه دانش

## نصب و راه‌اندازی

### پیش‌نیازها

- Node.js (نسخه 18 یا بالاتر)
- npm یا yarn
- کلید API از OpenAI
- توکن ربات تلگرام

### مراحل نصب

1. **کلون یا دانلود پروژه**

```bash
cd ldora
```

2. **نصب وابستگی‌ها**

```bash
npm install
```

3. **تنظیم متغیرهای محیطی**

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید:

```bash
cp .env.example .env
```

سپس فایل `.env` را ویرایش کرده و مقادیر زیر را وارد کنید:

```env
OPENAI_API_KEY=your_openai_api_key_here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
```

4. **ایجاد پایگاه دانش عطرها**

فایل‌های متنی حاوی اطلاعات عطرهای موجود را در پوشه `knowledge_base` قرار دهید. ربات به صورت خودکار تمام فایل‌های `.txt` را خوانده و از آن‌ها به عنوان منبع دانش استفاده می‌کند.

```bash
mkdir -p knowledge_base
# فایل‌های .txt حاوی اطلاعات عطرها را در این پوشه قرار دهید
# مثال: نام عطر، نت‌ها، توصیفات، و...
```

5. **اجرای ربات**

برای اجرای عادی:

```bash
npm start
```

برای حالت توسعه با **Hot Reload** (تغییرات خودکار اعمال می‌شود):

```bash
npm run dev
```

در حالت `dev`، با استفاده از `nodemon`، هر تغییری در فایل‌های `src/` یا `knowledge_base/` باعث restart خودکار ربات می‌شود.

## ساختار پروژه

```
ldora/
├── src/
│   ├── index.js          # نقطه ورود اصلی
│   ├── config.js         # مدیریت تنظیمات
│   ├── database.js       # مدیریت پایگاه داده SQLite
│   ├── knowledgeBase.js  # مدیریت پایگاه دانش
│   ├── aiService.js      # سرویس هوش مصنوعی
│   └── telegramBot.js    # مدیریت ربات تلگرام
├── knowledge_base/       # پوشه فایل‌های متنی پایگاه دانش
├── data/                # پوشه پایگاه داده (خودکار ایجاد می‌شود)
├── .env                 # فایل تنظیمات (باید ایجاد کنید)
├── .env.example         # نمونه فایل تنظیمات
├── package.json
└── README.md
```

## دستورات ربات

- `/start` - شروع مشاوره عطر
- `/help` - نمایش راهنما
- `/clear` - شروع مشاوره جدید (پاک کردن تاریخچه)
- `/profile` - نمایش اطلاعات پروفایل کاربر
- `/setcontext <متن>` - تنظیم اطلاعات اضافی (مثل سبک زندگی، شغل، و...)

## نحوه کار

1. **پایگاه دانش عطرها**: ربات فایل‌های `.txt` موجود در پوشه `knowledge_base` (حاوی اطلاعات عطرها) را خوانده و آن‌ها را به صورت chunk های کوچک‌تر تقسیم می‌کند. سپس با استفاده از OpenAI Embeddings، یک Vector Store ایجاد می‌کند.

2. **جستجوی معنایی**: وقتی کاربر درخواست مشاوره می‌دهد، ربات با استفاده از Vector Store، عطرهای مرتبط از پایگاه دانش را پیدا می‌کند.

3. **مشاوره هوشمند**: ربات با استفاده از LangChain و OpenAI، با در نظر گیری:
   - درخواست و نیاز کاربر
   - تاریخچه گفتگو و سوالات قبلی
   - اطلاعات عطرهای موجود در پایگاه دانش
   - پروفایل و زمینه کاربر (شغل، سبک زندگی، و...)
   
   مشاوره‌ای شاعرانه، عمیق و شخصی‌سازی شده ارائه می‌دهد که شامل:
   - توصیفات احساسی و جذاب از عطرها
   - پیشنهاد ترکیب‌های خلاقانه با زمانبندی دقیق
   - نقاط دقیق زدن عطر
   - پیشنهاد استایل متناسب

4. **ذخیره اطلاعات**: تمام پیام‌ها و اطلاعات کاربر در پایگاه داده SQLite ذخیره می‌شود. هر چت حافظه جداگانه دارد.

## تنظیمات پیشرفته

در فایل `.env` می‌توانید تنظیمات زیر را تغییر دهید:

- `OPENAI_MODEL`: مدل OpenAI (پیش‌فرض: gpt-4o-mini)
- `TEMPERATURE`: خلاقیت پاسخ‌ها (0 تا 1، پیش‌فرض: 0.7)
- `MAX_TOKENS`: حداکثر طول پاسخ (پیش‌فرض: 2000)
- `DB_PATH`: مسیر فایل پایگاه داده
- `KNOWLEDGE_BASE_PATH`: مسیر پوشه پایگاه دانش

## توسعه

برای افزودن ویژگی‌های جدید:

1. **افزودن دستور جدید**: در فایل `src/telegramBot.js` در متد `setupHandlers` دستور جدید را اضافه کنید.

2. **تغییر رفتار AI**: در فایل `src/aiService.js` می‌توانید prompt و منطق تولید پاسخ را تغییر دهید.

3. **افزودن جدول جدید**: در فایل `src/database.js` در متد `initDatabase` جدول جدید را اضافه کنید.
