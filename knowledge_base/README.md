# پایگاه دانش عطرها

این پوشه شامل اطلاعات عطرهای موجود در مجموعه L'DORA است.

## فایل اصلی

**`data.txt`** - فایل اصلی شامل اطلاعات کامل تمام عطرهای موجود به زبان انگلیسی و فارسی.

این فایل شامل:
- نام عطر
- نوع (Type)
- گروه بویایی (Group)
- نت‌های آغازی (Top Notes)
- نت‌های میانی (Middle Notes)
- نت‌های پایانی (Base Notes)
- توصیف حس و حال (Scent)
- مناسب برای (Ideal for)

## نحوه کار

ربات به صورت خودکار تمام فایل‌های `.txt` موجود در این پوشه را می‌خواند و از آن‌ها به عنوان منبع دانش استفاده می‌کند.

برای افزودن عطر جدید، می‌توانید:
1. اطلاعات را به فایل `data.txt` اضافه کنید
2. یا یک فایل `.txt` جدید ایجاد کنید

فرمت پیشنهادی برای هر عطر:
```
نام عطر
نوع: ... | گروه بویایی: ...
نت‌های آغازی: ...
نت‌های میانی: ...
نت‌های پایانی: ...
حس و حال: ...
مناسب برای: ...
```

## فایل‌های نمونه

- `example.txt` - راهنمای فرمت
- `perfumes_example.txt` - نمونه ساده عطرها
